# Paper Glide

Paper Glide is a minimalist mobile arcade game built in Godot and published on Google Play.

## 🎮 Gameplay
Tap to control a paper plane and avoid obstacles. The game focuses on timing, rhythm, and precision.

## ✨ Features
- One-touch control system
- Score and high score system
- Smooth mobile gameplay
- Persistent save system
- Simple arcade difficulty scaling

## 🛠️ Built With
- Godot Engine
- GDScript

## 📱 Release
Published on Google Play Store:
https://play.google.com/store/apps/details?id=com.saif.paperglide
